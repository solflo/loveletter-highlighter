# love letter syntax highlighter

basic syntax highlighter for the [love letter engine](https://github.com/solflo/loveletter) language. it has one color for comments and another for all commands and that's it. expects `.txt` and `.letter` files. the engine itself only takes in `script.txt`, and i don't think i'll change that, but i have my reasons to create a "fake" filetype extension ok.

## installation

- download this repo or the latest release
- open the vscode command palette (`ctrl + shift + p`)
- type in "Developer: Install Extension from Location"
- select the folder and it should work :)
